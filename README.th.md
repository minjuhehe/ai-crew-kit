# AI Crew Kit (ภาษาไทย)

**คุมทีม AI ทำโปรเจกต์จริงได้ แม้เขียนโค้ดไม่เป็น**

ใช้ AI เขียนโค้ดแล้วเจอแบบนี้ไหม:
- 🧠 **AI ลืม** — เปิดแชตใหม่ต้องเล่าโปรเจกต์ใหม่ทุกครั้ง
- 🎲 **AI เดาเอง** — ตั้งราคาเอง ลบข้อมูลเอง หรือเปลี่ยนสิ่งที่เราตัดสินใจไปแล้ว
- 💥 **AI สองตัวชนกัน** — ตัวหนึ่งแก้ทับงานอีกตัว
- ✅ **บอกว่า "เสร็จแล้ว!"** — แต่ไม่มีใครลองจริง

AI Crew Kit คือชุดไฟล์ข้อความ + คำสั่งก๊อปวาง ที่ทำให้ AI ทำงานเป็นทีมมีวินัย:
มีความจำกลาง มีบอร์ดงาน มีรายการเรื่องที่ต้องถามเจ้าของก่อนเสมอ และรีวิวงานกันเอง

ไม่ต้องติดตั้ง ไม่ต้องเขียนโค้ด ใช้ได้กับ Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI

## เริ่มใช้ (3 นาที)
1. เปิดเครื่องมือ AI ในโฟลเดอร์โปรเจกต์
2. วางคำสั่งจาก [START-HERE.md](START-HERE.md) (คำสั่งเป็นภาษาอังกฤษ วางได้เลย AI จะคุยกับเราเป็นภาษาไทย)
3. ตอบคำถามทีละข้อ — AI จะสร้างไฟล์ทั้งหมดและเสนอการ์ดงานแรกให้

ใช้ทุกวัน: คำสั่ง #1 เริ่ม → #3 ทำการ์ด → #4 ให้ AI อีกตัวรีวิว → เรากด merge → #8 ปิดงาน

## ในชุดมีอะไร
| ไฟล์ | ช่วยอะไร |
|---|---|
| `AGENTS.md` | ความจำกลาง AI ทุกตัวอ่านก่อนเริ่ม อัปเดตสถานะก่อนจบ |
| 🔴 Red Zone | เงิน, การลบ, ความปลอดภัย, ขึ้นของจริง, ใช้เงิน → AI ต้องหยุดถามเราก่อน |
| `docs/ROADMAP.md` | การ์ดงาน ทำทีละใบ มีเกณฑ์ "เสร็จเมื่อ…" ที่เราเช็กเองได้ |
| `docs/DECISIONS.md` | สิ่งที่เราตัดสินใจ ด้วยคำพูดของเราเอง (ข้อใหม่ชนะข้อเก่า) |
| `docs/adr/` | การตัดสินใจใหญ่ที่ล็อกแล้ว เปลี่ยนต้องให้เราอนุมัติ |
| `docs/BACKLOG.md` | ไอเดียของ AI จดไว้ที่นี่ แทนที่จะแอบทำ |
| `docs/HANDOFF.md` | เปลี่ยน AI หรือพักหลายวัน กลับมาต่อได้ไม่หลง |
| `PROMPTS.md` | คำสั่งสำเร็จรูป: เริ่มงาน ทำการ์ด รีวิว "เสร็จจริงไหม?" อธิบายให้ฟัง ปิดงาน |
